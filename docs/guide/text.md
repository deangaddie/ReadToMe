# Polish the text

Fix the words a narrator would stumble over before any audio is made. Leftovers from print, such as page numbers, footnote markers, running headers, words broken across lines and all-caps headings, are read aloud exactly as they appear.

## How

1. Choose **Review text** and read the book on the Book page.
2. Fix one line by hand in **Speakers** mode: open the item's menu and choose **Edit text**. For a volume, part or chapter heading, use **Edit title** on its menu.
3. For a pattern that repeats, choose **Edit with AI…**. Describe the change in plain words, for example “make the all-caps headings sentence case”, then choose **Analyze** and **Generate proposals**. Review each proposed change. Click a row to correct it by hand, or use **Ask AI again** with a hint. Then **Apply** the ones you keep. Edit with AI changes titles and paragraph text only, and never deletes text.
4. For a name or word the voice says wrong, use **Pronunciations**. Select the word in the text, choose **Add pronunciation**, and give a **Spoken form**, for example “WAT-sun” for “Watson”. It applies everywhere the word appears. Play **This sentence** to hear it.

Each of these edits discards the audio of the items it changes, so polish before generating audio.

## Done when

The text reads cleanly aloud. Choose **Confirm** on the Text row, or **Skip** when the book needs no changes. A later Edit with AI change marks the step as changed.
