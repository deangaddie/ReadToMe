# Import the book

Bring the book in from an epub or text file so ReadToMe has something to read. Creating a project stores the file; reading it in splits it into volumes, parts, chapters and paragraphs, which every later step works on.

## How

1. On the Projects page, choose **New project**. Fill in **Book title**, **Project title** and **Author**, then drop the book on **Drop the book here** (epub or txt, up to 100 MB) and choose **Create**. The project title names the project folder and follows the book title until you change it. The book title is the one the finished audiobook carries.
2. On the Overview, choose **Read book** on the Import row. An epub is split by its own table of contents. A text file comes in as one chapter, which the Structure step can split.
3. While you are on the Overview, add a cover on the project card (**Add a cover**: JPG, PNG or WebP, up to 10 MB). The cover is embedded in the exported audiobook. The same card edits the title and author.
4. If the book is narrated entirely by one voice, with no dialog to cast, turn on **Narrator only**: only narration then gets audio.

**Reread… (auto splits)** reads the source file in again from scratch. It deletes everything made since: attribution, audio, edits, inserted titles and pauses, and your confirmed and skipped steps. Use it only to start over.

## Done when

The Import row reads **Done** and shows how many items the book was read into.
