# Set the titles

Give every chapter the title the listener will hear and see. Chapter markers in the audiobook always use the node titles. A listener only hears a title if a spoken title paragraph is inserted for it.

## How

1. Make the titles right first. In the Book page tree, use **Edit title** on any volume, part or chapter that is untitled or wrong. Edit with AI can rename many at once, for example “rename every chapter to 'Chapter {n}'”. Check the book title and author on the Overview's project card too.
2. Choose **Add titles…**. Tick the levels to announce: **Book title**, **Volume titles**, **Part titles**, **Chapter titles**. A level the book doesn't have (one volume, say) is left out. Then choose **Add titles**. Each ticked level gets a spoken title paragraph at its start, read by the Narrator.
3. Add titles once. Running it again inserts a second copy. An inserted title is ordinary text, so a later **Edit title** does not change it: edit or delete the paragraph itself. A reread removes inserted titles.

Spoken titles are narration, so they need audio like any other line.

## Done when

Every node has the title you want and the spoken titles are in. Choose **Confirm** on the Titles row, or **Skip** for a book that needs no spoken titles. Renaming a node or changing the chapter structure later marks the step as changed.
