# Add the pauses

Decide where silence belongs between parts, chapters and scenes. Without pauses, the audiobook runs each paragraph straight into the next, and one chapter straight into the next.

## How

1. Choose **Add pauses** and confirm. It inserts a **Paragraph pause** between paragraphs in every chapter. At the end of each chapter it inserts a **Chapter pause**, or a **Part pause** or **Volume pause** where a part or volume ends. Where a pause already exists it adds none.
2. Add one-off gaps by hand, such as a scene break. In **Speakers** or **Audio** mode, open an item's menu and choose **Insert pause before** or **Insert pause after**, then pick the kind. **Delete pause** on a pause row removes it. Removing pauses later means deleting each one, so add them once the structure is settled. A reread removes them all.
3. Set how long each kind lasts in Settings, **Audio processing**, under **Pause durations**. The defaults are Volume 4000 ms, Part 3000 ms, Chapter 2500 ms, Paragraph 800 ms and Pause 500 ms. Durations apply when the audiobook is assembled, so you can change them at any time without regenerating anything.

Pauses are silence added at assembly. They need no audio of their own.

## Done when

The book has pauses, and the Pauses row reads **Done**. Choose **Skip** if you want the book to run on without any.
