# Layout (`src/Read2Me.Web/src/app`)

Folders are named for what they hold (`core/`, `ui/`, `api/`, `live/`, `shell/`, `theme/`, `pages/<area>/`, `activity/`, `history/`, `help/`, `ai-services/`, `setup-check/`, `shared/`), and a page lives under `pages/<area>/` beside its store, its `*Api` facade in `api/` and its pure `*-logic` files. Read the tree for the rest. These are the places a name doesn't lead you to:

- **The framework is `core/`**: `signals.ts`, `element.ts` (`R2mElement`, `define()`), `services.ts` (`use`, `provide`, `token`, `override`, `resetServices`), `router.ts` + `outlet.ts`, `dialog.ts` (`openDialog`), `styles.ts` (`adoptStyles`). The route table is `app.routes.ts`; section, page title and crumbs come from `route-meta.ts`'s `shellContext()`.
- **Wire types**: every type the OpenAPI document declares is generated into `api/schema.d.ts` under its C# name (with its XML doc as JSDoc) and re-exported by `api/index.ts`. `api/dtos.ts` holds only what the document doesn't describe (multipart fields, stored step settings). Never alias a generated name: a second export of it fails typecheck. `ApiClient` is the only caller of `fetch`, typed by path.
- **The project shell provides the Book page's services.** `r2m-project-shell` (`pages/project/`) opens the project, holds its hub group, and provides `ProjectStore`, `BookStore`, `StepRunner`, `BookEditor` (the one book write path), `SelectionWorkflow`, `SpeakerAssigner` and `AudioGenerator` to its child routes; a row partial reaches them through `use(X, event.currentTarget)`. Those classes live in `pages/book/`. The Overview page is in `pages/project/`, not its own folder.
- **The edit gate and step viewing live in `api/step-view.ts`**: `StepView` (the viewed History step), `READS_AT_STEP` (the reads `ApiClient.get` sends `?at=` on while a step is viewed) and the pure `blockedReason` behind `BookEditor.blocked(local?)` (viewing > stale > local reason). The one read-only flag is `StepView.readOnly(folder)`, surfaced as `ProjectStore.readOnly`, `BookEditor.blocked()` and `CastStore.readOnly`.
- **Pronunciations are split across two folders**: the Book page's marks, card, panel and selection pill are in `pages/book/`; the page, the shared `r2m-pronunciation-editor`, `PronunciationWriter` and `TryOutPlayer` are in `pages/pronunciations/`.
- **Series UI is in `pages/projects/`** (the shelf): `SeriesActions`, `series-pickers`, `series-cast-board.ts` and `series-voice-editor.ts`. `SeriesApi` is in `api/`.
- **The Node menu** is one shared `r2m-node-menu` (`pages/book/`), with `structure-node-menu` shared by the structure tree and the Book page headings.
- **Permanent-change confirms** are one `permanent-changes.ts` per feature folder (`pages/book/`, `pages/projects/`, `pages/project/`, `pages/pronunciations/`, `pages/cast/voices/`, `pages/settings/llm/`, `activity/`), never in `ui/`.
- **Provider settings** (`pages/settings/providers/`) are four page elements over one `ProviderSettingsPage`, one tag per area (`PROVIDER_PAGE_TAGS` in `provider-area.ts`), because the outlet keeps an element whose tag matches.
- **App-wide stores** created once by `use()` and never disposed: `ActivityStore` (`activity/`), `AiServicesStore` (`ai-services/`), `SetupCheckStore` (`setup-check/`; its pure `surfacing` holds `landingPath`, where `/` redirects), `HistorySheetState` (`history/`), `ThemeService` (`theme/`).
- **App-level `shared/`** holds the AI gate, `preflight.ts` (`use(Preflight).ensureReady('<task>')`) and `enqueue.ts` (`enqueueWithPreflight`), and the unsaved-changes guard `unsaved-changes.ts` (`confirmDiscard()`, paired with a page's `hasUnsavedChanges()` for the router's `guardUnsaved`). It also holds the settings helpers `config-form.ts` and `settings-schema.ts` (the provider schema wire shape); `pages/settings/shared/` holds only `r2m-managed-service-status`.
- **Help text** comes from the repo's `docs/guide/<step>.md`, rendered by `bun run help` into the committed `help/help.generated.ts`.
- **Styles**: tokens, fonts and the global primitive CSS are in `src/styles/global.css`.
- **Spec helpers** are in `src/testing/`: `FakeApi`, `FakeLive` (`emit(family, message)`, `resync(snapshot)`), `FakeConnection` (`fake-hub-connection.ts`, for specs of the real `LiveService`), `fake-timers.ts`, `fake-navigation.ts`, `live-messages.ts` (hub messages with unset fields null, as on the wire), `settings-fields.ts`, `structure-rules.ts`.
