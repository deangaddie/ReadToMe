The native front end has not been built

This host serves the native app from wwwroot/app2/, and that folder has no index.html.

Build it once from the repo root, then reload this page:

pwsh scripts/build-native.ps1

For development with live reload, run bun run dev in src/Read2Me.Native instead and open http://localhost:4300/app2/. It proxies API calls to this host.

The Angular app is still served at /app/.
